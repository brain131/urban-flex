# URBAN TONE

Welcome to the repository for **URBAN TONE**, a modern, responsive e-commerce storefront built entirely from scratch using **HTML5** and **CSS3**. This project features a clean look, fluid layouts, and a curated product catalog designed for the modern fashion-forward individual.

---

## Features

 **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
**Interactive Navigation:** Includes links for Home, Collections, and Contact forms.
 **Instant Search Header:** Clean input integration with "Enter Key to Search".
 **Dynamic Product Grid:** Visually structured layout featuring item pricing in dual currencies (USD & KSH) with interactive "Add to Cart" components.

## Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
You only need a web browser and a code editor (like VS Code).

### Installation
 Clone the repository:
   ```bash
   gitt clone https://github.com
   ```
 Navigate into the project folder:
   ```bash
   cd urban-tone
   ```
 Open `index.html` in your favorite browser to view the store.
