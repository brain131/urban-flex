# URBAN FLEX

Welcome to the repository for **URBAN FLEX**, a modern, responsive e-commerce storefront built entirely from scratch using **HTML** and **CSS**. This project features a clean look, fluid layouts, and a curated product catalog designed for the modern fashion-forward individual.
## Features

 **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
**Interactive Navigation:** Includes links for Home, Collections, and Contact forms.
 **Instant Search Header:** Clean input integration with "Enter Key to Search".
